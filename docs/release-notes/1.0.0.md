Search the tabs, bookmarks and history of Firefox, Chrome, Safari, Brave and Edge from Alfred.

- `tab` searches open tabs in running browsers. Return brings the tab to the front.
- `bmk` searches bookmarks. Return opens the bookmark in its original browser; ⌘Return opens it in your default browser.
- `hist` searches history, newest first, with up to 50 results per browser. Return and ⌘Return work as they do for bookmarks.

You can change the keywords and enable or disable each browser in the workflow's configuration.

## Install

1. Firefox only: install the add-on from https://addons.mozilla.org/firefox/addon/browser-search-for-alfred/. It requires Firefox 140 or later.
2. Download the workflow from this release and open the file to import it into Alfred.
3. Firefox only: type `tab`, then press Return on "Set up Firefox". This writes two small files that allow Firefox to start the workflow's helper. The README lists these files and how to remove them.

For bookmarks and history in Safari, Chrome, Brave and Edge, the workflow displays an "Allow Alfred to read ..." result if macOS blocks access. Return opens Full Disk Access in System Settings, where you enable Alfred. For tabs in these four browsers, macOS asks once whether Alfred may control the browser.

## What the add-on can see

When you install the add-on, Firefox lists its permissions: access to your tabs, bookmarks and browsing history, and "Exchange messages with programs other than Firefox". The last one is how the add-on talks to the workflow's helper on this Mac. Firefox's data line says the add-on collects browsing activity and bookmarks. The add-on uses this data only to answer workflow searches. Nothing leaves your Mac: the add-on and workflow make no network requests. Tabs in Firefox's private windows are not listed.

## Known limits

- Safari does not tell Alfred which windows are private, so tabs in Safari's private windows are listed. Firefox, Chrome, Brave and Edge never list private windows.
- Firefox bookmarks and history are available only while Firefox is running. Searching never starts a browser, but opening a bookmark or history result may.
- Brave and Edge have been tested with stand-ins, not yet on real browsers.
- Bookmarks and history in Safari, Chrome, Brave and Edge may need Full Disk Access for Alfred.
